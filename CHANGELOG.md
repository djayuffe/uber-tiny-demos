# Changelog

## [3.5.0] - 2026-10-10

- Inventory now 44 programs: adds WARP (72 B) from `uber256-lab` v1.6.0.

## [3.4.0] - 2026-10-10

- Inventory now 43 programs: adds LATCH (82 B, VGA graphics-controller cellular automaton) from `uber256-lab` v1.5.0.

## [3.3.0] - 2026-10-10

- Inventory now 42 programs: adds OVERMAX (8 bytes) from `uber-micro-demos` v1.9.0.

## [3.2.0] - 2026-10-10

- INVENTORY.md gains a preview image for every one of the 41 programs (`docs/thumbs/`), generated alongside the list.

## [3.1.0] - 2026-10-10

- Inventory now 41 programs: adds ESCHER (137 B, CRTC-only animation) and CHLADNI (224 B, FPU plate) from `uber256-lab` v1.4.0.

## [3.0.0] - 2026-10-10

- The index now covers the whole family: 39 programs in 7 repositories, from the 4-byte `BIG.COM` to the 11 KB `UBERSHOW.COM`.
- New **INVENTORY.md**, generated by `tools/gen_inventory.py` from each repository's latest release and README, with every program's size and description.
- README rewritten: a size ladder with thumbnails (adds the 29 micro demos and the five `uber256-lab` demos), a repository table, an expanded list of shared hacks, and how the family is tested.

## [2.0.0] - 2026-10-10

- This repository is now an **index**. The demos live in their own repositories, each with a build gate,
  an emulated-CPU test, CI and tag-driven releases:
  [uber10-dos-demo](https://github.com/djayuffe/uber10-dos-demo) (10 bytes),
  [uber128-dos-demo](https://github.com/djayuffe/uber128-dos-demo) (77),
  [uber256-dos-intro](https://github.com/djayuffe/uber256-dos-intro) (131, the moire) and
  [uber256-rotozoomer](https://github.com/djayuffe/uber256-rotozoomer) (171, the rotozoomer).
- The sources and tests moved with them; releases v1.0.0 and v1.1.0 still carry the earlier binaries.

## [1.1.0] - 2026-10-09

UBER8 5 bytes, UBER128 79, UBER256 171 (from 8 / 118 / 237).

## [1.0.0] - 2026-10-09

First release: UBER8 (8 bytes), UBER128 (118), UBER256 (237).
